## Estrutura obrigatória
1. Gancho inicial integrado ao assunto.
2. Introdução real do Radar dos Games conforme os Masters aprovados; não substituir por drawtext, emoji, tela preta ou intro inventada.
3. Narração Thalita PT-BR com o mesmo ritmo/tratamento dos Masters.
4. Imagem/gameplay/B-roll deve ilustrar exatamente a frase narrada naquele momento.
5. Cards/encartes são overlays contextuais e entram somente quando a informação correspondente estiver sendo dita. Não usar timestamps fixos independentes da fala.
6. Cortes/transições seguem a narração e mantêm movimento visual.
7. CTA/encerramento no padrão dos Masters.
8. 1280x720, 30fps para Master, salvo mudança deliberada posterior.

## Gate de reprovação
Reprovar automaticamente se: intro real estiver ausente; card estiver fora do contexto da fala; mídia não corresponder ao assunto narrado; voz divergir do padrão aprovado; houver cards genéricos usados como cenas principais; ou a montagem parecer slideshow/fallback.

Os arquivos binários de referência foram fornecidos diretamente na conversa e devem ser analisados quadro a quadro/localmente quando disponíveis. Este documento registra o padrão para impedir regressão no pipeline.
