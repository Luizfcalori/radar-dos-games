Como a integração funciona

A ferramenta auxilia a preparação e o envio de vídeos para o canal Radar dos Games. O acesso à API do YouTube é autorizado pelo administrador via Google OAuth. A integração consulta a identidade do canal autorizado e permite enviar vídeos e seus metadados.

O uso é restrito à administração do próprio canal. Este site é informativo e não solicita senhas, códigos ou tokens.

Permissões utilizadas

  • youtube.readonly: consultar informações do canal para confirmar o destino.
  • youtube.upload: enviar vídeos e respectivos títulos, descrições e configurações.
